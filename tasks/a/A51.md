# A51 - ai wizard: chat UI actions and model-aware prompts
[Overview](../../BASED.md)

Improve AI wizard chat controls so copied chat output is useful, tool results show their tool name, and prompt requests use the selected model.

## Context
- `packages/canvas/src/components/AiWizzard/`
- `packages/api-agent/src/contract.ts`
- `packages/api-agent/src/api.wizzard.prompt.ts`
- `packages/service-agent/src/AgentService.ts`
- `docs/internal/llm.widget-system.md`

## Plan
1. Add a copy-chat action to the composer overflow menu and serialize visible chat messages as markdown.
2. Thread the selected composer model through `ChatTab`, `AiWizzard`, ORPC prompt input, and `AgentService`.
3. Apply the selected model to the active Pi agent session before prompting.
4. Show tool result labels as `toolResult - <toolname>` when the message includes a tool name.
