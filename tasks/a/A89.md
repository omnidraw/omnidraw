# A89 - canvas persistence: add the shared item contract and JSONB canvas_items
[Overview](../BASED.md)

Define one persisted canvas-item vocabulary around Cangine nodes and the
queryable JSONB schema used by the authoritative CanvasService.

## Result

`@vibecanvas/canvas-contract` now owns item snapshots, commands, events,
queries, preconditions, namespaced extensions, and validation. It uses
Cangine `TSceneNode` directly.

The canonical schema stores one authored node per STRICT `canvas_items` row as
SQLite JSONB, with generated query columns and indexed canvas, hierarchy, kind,
and widget-identity access. `CanvasItemStoreTurso` provides tenant-scoped
snapshots, indexed queries, bounded transactional mutation, canvas/item
revision CAS, and synchronous widget-instance metadata updates.

Runtime layers, portal configuration, selection, previews, and other transient
state are not persisted.
