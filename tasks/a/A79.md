# A79 - onboarding: welcome canvas with inline tutorial
[Overview](../BASED.md)

Turn the first automatically created canvas into a useful welcome experience instead of an empty “Untitled Canvas.”

## Context

First-time startup currently creates an empty canvas named `Untitled Canvas` in [`apps/frontend/src/startup-canvas.ts`](../../apps/frontend/src/startup-canvas.ts), with bootstrap coverage in [`apps/frontend/src/startup-canvas.test.ts`](../../apps/frontend/src/startup-canvas.test.ts). The result gives new users no guidance once they reach the canvas.

The default starting canvas should have a clearer, intentional name and contain an inline visual tutorial made from normal canvas elements. It should introduce the essential interactions and tools without requiring a modal or separate onboarding screen.

## Plan

1. Choose a concise welcome-oriented name for the automatically created canvas.
2. Define a maintainable default tutorial scene using supported canvas elements and APIs.
3. Seed that scene only when creating the first default canvas; do not alter existing or manually created canvases.
4. Arrange the tutorial so it is readable at the initial camera position and remains editable like ordinary canvas content.
5. Add focused tests for the default name, seeded content, and first-run-only behavior.
