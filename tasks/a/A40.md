# A40 - canvas: non-sandboxed terminal widget plugin
[Overview](../BASED.md)

Add a trusted ArrowJS terminal widget plugin backed by the existing CLI PTY APIs.

## Context

Relevant files:
- `packages/canvas/src/services/widget/WidgetManagerService.ts`
- `packages/canvas/src/plugins/filesystem/Filesystem.plugin.ts`
- `apps/cli/src/plugins/filesystem/FilesystemPlugin.ts`
- `apps/cli/src/plugins/pty/PtyPlugin.ts`
- `packages/canvas/src/components/terminal/`

The filesystem plugin is the local pattern for trusted widgets: create an oRPC websocket service, register a widget kind with `WidgetManagerService`, add an action tool, and create centered persisted widget elements.

The terminal widget should not restore backend PTY sessions. Restoring a canvas creates a fresh PTY from the persisted cwd. Widget cleanup kills the active PTY through the cleanup callback returned by `renderDom`.

## NOTES

- PTY websocket stream uses `/api/pty/:ptyID/connect?workingDirectory=...` from the CLI PTY plugin.
- The widget creates a new PTY on every mount; no localStorage/session restore is used.
- The cleanup callback closes the frontend websocket and calls `api.pty.remove` for the active PTY.
- The existing widget traffic-light close button is intentionally not wired in this change.
- Terminal tabs persist tab metadata in the widget payload, but each mounted tab creates a fresh PTY session.
- Tab context menu supports rename, close, close others, close right, and close left.
- Clicking empty tab-strip space opens a new tab using the active/default cwd.
