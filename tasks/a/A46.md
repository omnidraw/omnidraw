# A46 - add widget wizard for AI-created widgets using pi.dev SDK harness
[Overview](../BASED.md)

Add a widget wizard that helps create new widgets with AI, using pi.dev as the SDK harness.

## Context

We want a guided flow for creating new canvas widgets with AI assistance. The wizard should use pi.dev as the SDK harness so generated widgets follow the expected local development and integration path.

Relevant areas to inspect:
- widget SDK and widget registration flow
- actor/widget creation UX
- pi.dev SDK harness integration points

## Plan

### Define wizard flow

Specify the minimal prompt/input steps needed to create a widget and preview it locally.

### Integrate pi.dev harness

Use pi.dev as the SDK harness for generation, validation, and local iteration.

### Ship first usable path

Prefer a small guided flow that creates one working widget over a broad generic builder.
