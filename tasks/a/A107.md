# A107 - sidebar: no hover color on section titles, compact "+ Add" widget button
[Overview](../../BASED.md)

Two small sidebar UI polish items:
1. Hovering a section title (CANVASES / RESOURCES / WIDGETS) paints a colored background — remove that hover color.
2. The widget row "Add to canvas" action hover looks ugly (full-row-height tinted slab). It should look like a small button, and the label shrinks to "+ Add".

## Context

Section titles and their hover styles live in two places (two side-by-side sidebar implementations of section headers):

- `packages/ui-ai-chat/src/sidebar/components/Sidebar.tsx:153` and `:189` — Canvases/Resources section toggle buttons (`styles.sectionToggle`).
- `packages/ui-ai-chat/src/sidebar/components/Sidebar.module.css:162-166` — `.sectionToggle:hover, .sectionAdd:hover { background: var(--accent); color: var(--foreground); }` — this paints the accent (yellowish in light theme) background behind the section title on hover.
- `packages/ui-ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.tsx:163` — Widgets section toggle (`styles.sectionToggle`).
- `packages/ui-ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.module.css:6` — `.sectionToggle:hover, .menuTrigger:hover, .groupDisclosure:hover, .groupMenuTrigger:hover { background: var(--accent); color: var(--foreground); }` — same hover color for the Widgets title.

"Add to canvas" button:

- `packages/ui-ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.tsx:143-154` — the add `<Button>` with text `Add to canvas`.
- `packages/ui-ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.module.css:18-26`:
  - `.widgetRow` is `display: grid; grid-template-columns: minmax(0, 1fr) auto; align-items: stretch` — the add button stretches to full row height.
  - `.addButton` (line 20) has no border/background, only padding, so on hover (line 21) the whole vertical slab gets a primary tint and primary text — reads as an ugly full-height stripe, not a button.
  - `.draftAddButton` (line 25-26) — draft variant in warning color, same slab problem.

Note: `Plus` icon already used in `Sidebar.tsx` (import from `lucide-solid/icons/plus`); WidgetsSidebarSection.tsx does not import it yet.

## Plan

### 1. Remove hover color from section titles

- `Sidebar.module.css:162-166`: split the rule — keep `.sectionAdd:hover` (the "+" add button keeps its hover), remove `.sectionToggle:hover` entirely so the title keeps `color: var(--muted-foreground)` and transparent background on hover. Keep `:focus-visible` ring for keyboard users (unchanged).
- `WidgetsSidebarSection.module.css:6`: remove `.sectionToggle:hover` from the combined selector; keep `.menuTrigger:hover, .groupDisclosure:hover, .groupMenuTrigger:hover` (group rows are not section titles).

### 2. Restyle "Add to canvas" → compact "+ Add" button

- `WidgetsSidebarSection.tsx`:
  - Import `Plus` from `lucide-solid/icons/plus`.
  - Replace the button content `Add to canvas` with `<Plus size={10} /> Add`.
  - Keep `aria-label={`Add ${label} ${value.source} to canvas`}` and `title` as-is (accessibility text stays descriptive).
- `WidgetsSidebarSection.module.css`:
  - `.addButton`: make it a real small button — `align-self: center; gap: .125rem; height: 1.375rem; padding: 0 .375rem; border: 1px solid var(--border); border-radius: 0; background: var(--background);` (matches the square, border-radius: 0 house style).
  - `.addButton:hover`: `border-color: var(--primary); background: color-mix(in srgb, var(--primary) 12%, transparent); color: var(--primary);` — tint now only fills the small button box.
  - `.draftAddButton:hover`: keep warning tint, add `border-color: var(--warning)`.

### 3. Verify

- `bun run dev`, open sidebar: hover CANVASES/RESOURCES/WIDGETS titles → no background change; "+" section buttons and group rows still highlight.
- Widget rows: "+ Add" shows as a small bordered button vertically centered in the row; hover fills only the button; draft rows use warning color.
- Run the existing test suite for the touched package: tests in `packages/ui-ai-chat/tests/sidebar/WidgetsSidebarSection.test.tsx` reference the button — check whether any assertion matches the "Add to canvas" text and update if needed.
