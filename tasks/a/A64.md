# A64 - cli: uninstall command removes binary and data
[Overview](../../BASED.md)

Add a CLI uninstall option that removes the installed Vibecanvas binary and all local Vibecanvas data.

## Context
The curl installer places the binary under `~/.vibecanvas/bin` by default and stores local app data/config/state/cache under the configured XDG/Vibecanvas paths. Users need a supported way to fully remove Vibecanvas from a machine.

Relevant files:
- `scripts/install.sh`
- `apps/cli/src/plugins/cli/cmds/`
- `apps/cli/src/config`

## Plan
1. Decide command shape, likely `vibecanvas uninstall` with confirmation and `--yes`.
2. Remove the installed binary and install directory when owned by Vibecanvas.
3. Remove local Vibecanvas config/data/state/cache directories, including database migrations and app data.
4. Avoid deleting user project files or unrelated parent directories.
5. Print clear summary and warnings before destructive actions.
6. Add tests/docs for dry-run/confirmation behavior if supported.
