# A81 - docs: comprehensive UI screen atlas
[Overview](../BASED.md)

Create an organized, compact screenshot atlas for the important Vibecanvas pages, workspace areas, and UI states.

## Context

The existing [`SCREENS.md`](../../docs/internal/screens/SCREENS.md) only lists eight unlabelled PNGs. The atlas needs to classify those captures, add important missing states from the live app, keep the image payload small, and remain useful as a visual product reference.

## Plan

### 1. Inventory

- Map routes, major workspace sections, dialogs, menus, and representative states.
- Classify the supplied screenshots and identify gaps.

### 2. Capture and organize

- Run the product locally and capture missing states through the in-app browser.
- Give every retained screenshot a stable descriptive filename and place it beside the atlas.
- Write concise captions and a coverage index in `SCREENS.md`.

### 3. Optimize and verify

- Resize/compress screenshots for documentation use.
- Verify image links, dimensions, file sizes, and Markdown rendering.
