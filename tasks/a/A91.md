# A91 - widget state: add a centralized JSONB service
[Overview](../BASED.md)

Preserve widget `get/change/subscribe` with one centralized, versioned JSON
state authority per widget instance.

## Result

The STRICT `widget_instance_states` table stores one JSONB row per active
widget instance. `@vibecanvas/service-widget-state` provides exact-identity
authorization, compare-and-swap updates, bounded replay/resync, JSON-only
validation, byte/depth/node quotas, rate limits, and deterministic cleanup.

The API, frontend host bridge, and Capsule-facing capability retain their
public state semantics. Runtime-load authorization resolves indexed canvas and
widget identity without loading a whole canvas.
