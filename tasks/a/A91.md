# A91 - widget state: centralized JSONB authority without product regression
[Overview](../BASED.md)

Replace Automerge widget-instance state with one centralized, versioned JSONB
authority while preserving widget hosting, placement, Preview, and UI behavior.

## Scope boundary

This task replaces widget state storage and transport. It does not authorize
deleting widget frames, placement, cloning, canvas portals, runtime mounting,
draft Preview, the widget inspector, or AI-generated widget flows.

## Plan

1. Keep one `widget_instance_states` JSONB row per active widget instance.
2. Preserve versioned `get/change/subscribe`, validation, quotas, rate limits,
   authorization, replay, and resync.
3. Restore widget product components and adapt their state ports to
   WidgetStateService.
4. Preserve immutable published revision identity and per-placement instance
   identity through canvas commands.

- Concurrent writers have one deterministic CAS winner.
- All widget UI and canvas behaviors represented in `SCREENS.md` remain present.
- No restored widget code imports Automerge or stores widget state in
  `canvas_items`.
