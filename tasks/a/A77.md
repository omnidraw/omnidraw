# A77 - AI chat: surface assistant and widget-level errors
[Overview](../BASED.md)

Show Pi assistant failures in chat history and surface transport or operation failures near the composer. This intentionally does not change credential resolution or the underlying provider failure.

## Context
Pi reports failures after prompt acceptance through assistant messages with `stopReason: "error"` and `errorMessage`. The chat renderer currently reads only message content, so an error with empty content appears as a blank response. Connect, event-stream, prompt, cancel, and attachment failures are otherwise only logged.

## Plan
1. Add pure helpers that safely extract assistant errors and normalize unknown operation errors.
2. Render durable assistant errors inline and transient widget errors near the composer.
3. Add focused unit and rendered-component coverage.
