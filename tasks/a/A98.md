# A98 - canvas: add line shape controls to selection styles
[Overview](../BASED.md)

Let users change a selected line or arrow between **Straight**, **Curved**, and
**Elbow** from the Selection styles menu.

## Context

The Selection styles menu currently exposes color, width, and opacity for a
connector, but no line shape:

- [`SelectionStyleMenu/index.tsx`](../../packages/canvas/src/components/SelectionStyleMenu/index.tsx)
  renders the visible controls.
- [`fn.selection-style.ts`](../../packages/canvas/src/components/SelectionStyleMenu/fn.selection-style.ts)
  derives selection state and applies paint patches.
- [`Canvas.tsx`](../../packages/canvas/src/components/Canvas.tsx) connects the
  menu to the active canvas runtime.

Cangine already has the required geometry. Connector routing supports straight,
orthogonal, quadratic, and Bézier paths. Its
`IPathInteractionController.setSegmentMode()` API exposes the simpler product
modes `straight`, `smooth`, and `elbow`. The standard editor session owns this
controller, but [`runtime.ts`](../../packages/canvas/src/runtime.ts) does not
currently expose a narrow way for the menu to use it.

## Plan

![Selection styles with Straight, Curved, and Elbow controls](A98.png)

### 1. Show the current line shape

- Add a **LINE** section for one selected connector, including connectors
  created by both the Line and Arrow tools.
- Show three choices: **Straight**, **Curved**, and **Elbow**.
- Map Cangine routing to the product labels:
  - `straight` → Straight
  - `quadratic` or `bezier` → Curved
  - `orthogonal` → Elbow
- Do not show this section for shapes, text, widgets, images, pen paths, mixed
  selections, or manual connector routes.
- Keep the mapping in a small pure function beside the existing selection-style
  projection.

### 2. Use the existing path controller

- Add a narrow runtime operation for changing the selected connector's segment
  mode. Do not expose the whole mutable editor session to Solid UI.
- Route the menu choices to
  `IPathInteractionController.setSegmentMode('straight' | 'smooth' | 'elbow')`.
- Keep line-shape changes separate from paint patches; color, width, and opacity
  continue through `txApplySelectionStyle`.
- Let the existing Cangine mutation port, CanvasService authority, history, and
  path overlay own the durable change and handle refresh.

### 3. Preserve connector meaning

- Switching shape must preserve connector identity, endpoints, node bindings,
  gaps, arrowheads/markers, stroke, opacity, transform, and ordering.
- Curved mode should create usable default Bézier controls when none exist.
- Elbow mode should use orthogonal routing and its existing waypoint behavior.
- Straight mode should remove curve-specific routing without leaving stale
  control handles.
- Undo and redo must restore both routing and editable handles.

### 4. Verify the menu and geometry

- Add pure tests for visibility and routing-to-label projection.
- Add component coverage for selected state, accessible pressed state, and
  keyboard activation.
- Add canvas integration coverage for Line and Arrow connectors across all
  three modes, including undo/redo and endpoint/marker preservation.
- Confirm the selected path overlay updates immediately and remains editable
  after every switch.
- Verify the panel remains usable in light/dark themes and at its current
  maximum height.
- Update the Selection styles capture in
  [`SCREENS.md`](../../docs/internal/screens/SCREENS.md).

## Acceptance criteria

- Selecting a Line or Arrow connector shows the **LINE** section.
- The current shape is visibly and accessibly selected.
- Each choice changes the connector immediately and persists through reload.
- Undo and redo restore the previous shape.
- Switching shape never removes arrowheads, endpoint bindings, or visual style.
- Unsupported and mixed selections do not show misleading line controls.

## NOTES

- The UI says **Curved**; `smooth` remains the internal Cangine segment-mode
  name.
- This task reuses Cangine's existing routing conversion. Do not create a
  second curve representation in Vibecanvas.
- The mockup was generated with the built-in image tool from a browser capture
  of the current Selection styles menu, then resized and compressed to a
  39,383-byte PNG. The written behavior is authoritative.
