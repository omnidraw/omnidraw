# A90 - canvas: implement the authoritative CanvasService
[Overview](../BASED.md)

Add the central server authority for snapshots, indexed queries, atomic
commands, revisions, and realtime multiplayer events.

## Result

`@vibecanvas/service-canvas` now provides one serialized command lane per
active canvas. It authorizes every operation, validates bounds,
preconditions, hierarchy, Cangine nodes, and widget identity, then commits
only touched rows and exactly one canvas revision.

The service publishes exact changed items/deletions after commit, keeps a
bounded revision event ring, supports replay or resync, bounds active cache
state, and releases subscribers and cached rows deterministically.
