# A80 - codex: prompt for a branch in fresh worktrees
[Overview](../BASED.md)

Add project-local Codex startup guidance that asks the agent to create a named
branch when a new chat starts in a Codex-managed detached worktree.

## Context

Codex lifecycle hooks can add developer context at session startup, but they do
not rewrite the literal user prompt. Codex-managed worktrees start in detached
HEAD state, while the main checkout and branch-backed worktrees do not.

Relevant files:

- `.codex/hooks.json`
- `.codex/hooks/worktree-branch-session-start.ts`
- `.codex/hooks/README.md`

## Plan

1. Register a project-local `SessionStart` hook for `startup`.
2. Detect a linked Git worktree with a detached HEAD.
3. Emit the branch naming instruction as hook-provided developer context.
4. Smoke-test both the main checkout and a detached managed worktree.
