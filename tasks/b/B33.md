# B33 - ai wizard: chat does not reconnect after OAuth API key login
[Overview](../BASED.md)

After setting an OAuth/API login from the new login flow, switching back to chat leaves chat unusable until a manual page reload.

## Context
The AI wizard chat connection appears to be initialized before provider credentials are available. After the user completes the new OAuth/API login flow and returns to chat, the frontend should internally reconnect/refresh the wizard chat/session state instead of requiring a browser reload.

Relevant areas:
- `packages/canvas/src/components/AiWizzard/index.tsx`
- `packages/canvas/src/components/AiWizzard/tabs/ChatTab.tsx`
- `packages/canvas/src/components/AiWizzard/tabs/SettingsTab.tsx`
- agent settings/login APIs used by the AI wizard

## Plan
Investigate the AI wizard settings/login flow and the chat connection lifecycle. Ensure successful OAuth/API key setup triggers the chat connection to reconnect or refresh settings/session state so chat works immediately.
