# B35 - ai wizard: image attachments are not sent to Pi
[Overview](../../BASED.md)

Fix AI wizard image prompts so attached/pasted images reach the Pi agent.

## Context
The AI wizard composer can collect image files and show local previews in [`packages/canvas/src/components/AiWizzard/ChatComposer/ChatComposer.tsx`](../../packages/canvas/src/components/AiWizzard/ChatComposer/ChatComposer.tsx), but submit drops them before the backend call. [`packages/canvas/src/components/AiWizzard/tabs/ChatTab.tsx`](../../packages/canvas/src/components/AiWizzard/tabs/ChatTab.tsx) only sends text/model/thinking level. [`packages/api-agent/src/contract.ts`](../../packages/api-agent/src/contract.ts) does not accept images, and [`packages/service-agent/src/AgentService.ts`](../../packages/service-agent/src/AgentService.ts) calls `session.prompt(text)` without image options.

Pi already supports prompt images as `session.prompt(text, { images })` with image content shaped like `{ type: "image", data: base64, mimeType }`, and Pi session persistence stores finalized user messages. Keep complexity down by using Pi session storage for AI chat images instead of Vibecanvas `media_files`; only use `media_files` when an image becomes a canvas/media asset.

## Plan
1. Extend the AI wizard prompt request with optional image attachments.
2. Convert frontend `File` attachments to base64 before sending.
3. Allow image-only prompts by supplying a small fallback text on the backend if needed.
4. Pass images to Pi via `session.prompt(text, { images })`.
5. Add basic validation/limits for MIME type, size, and count.
