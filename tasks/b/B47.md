# B47 - image delete: remove media_files row
[Overview](../../BASED.md)

Deleting a persisted image element must also remove its backing `media_files` row.

## Context
- `packages/canvas/src/plugins/image/Image.plugin.ts` registered image create/update/clone behavior but no `onDelete` lifecycle hook.
- `packages/canvas/src/services/element/ElementService.ts` already dispatches registered `onDelete` hooks after the CRDT delete commits.
- `packages/api-file/src/api.remove-file.ts` already validates `/files/:id.ext` URLs and calls `db.file.deleteById()`.
- The missing link was canvas image lifecycle wiring to `api.file.remove`.

## Plan
- Add a local image deletion transaction helper with injected API and notification portals.
- Register it as the image element's `onDelete` lifecycle behavior.
- Verify the persisted image URL is sent to `api.file.remove` and errors are reported.
