# B59 - `AuthStorage` export removed from `@earendil-works/pi-coding-agent` 0.80.10

[Overview](../BASED.md)

`packages/service-agent` fails to start because `@earendil-works/pi-coding-agent` v0.80.10 no longer exports `AuthStorage` from its main `dist/index.js`. The class was removed from the public API; auth/storage operations now go through `ModelRuntime`.

## Context

The error blocks `bun run dev`:

```
[cli] SyntaxError: Export named 'AuthStorage' not found in module
'.../@earendil-works+pi-coding-agent@0.80.10/.../dist/index.js'
```

`packages/service-agent/src/AgentService.ts` imports `AuthStorage` and uses it in ~12 sites:

- Import (line 1)
- Field type `authStorage: AuthStorage` and `modelRegistry: ModelRegistry` (lines 172-173)
- Init `AuthStorage.create(...)` + `ModelRegistry.create(...)` (lines 245-246)
- `authStorage.login(...)` → OAuth login flow (line 794)
- `authStorage.logout(...)` (line 843)
- `authStorage.set(...)` → persist API key (line 847)
- `authStorage.remove(...)` (line 854)
- `authStorage.list()` (line 864)
- `modelRegistry.getAll()` + `modelRegistry.getAvailable()` (lines 865-866)
- `modelRegistry.find(...)` (line 366)
- `createAgentSessionServices({ authStorage, modelRegistry, ... })` (lines 1142-1143)

The replacement API is `ModelRuntime` (still exported), which wraps credential storage internally and exposes `login()`, `logout()`, `setRuntimeApiKey()`, `listCredentials()`, `getModels()`, `getModel()`, `getAvailableSnapshot()` etc.

`ModelRuntime.create({ authPath, modelsPath })` replaces `AuthStorage.create()` + `ModelRegistry.create()`.

The package also has a strict `exports` map (`"."` and `"./rpc-entry"` only) so subpath imports like `@earendil-works/pi-coding-agent/dist/core/auth-storage.js` are rejected by TypeScript bundler module resolution.

The `AuthStorage` class file still exists at `dist/core/auth-storage.js` but is not re-exported from `dist/index.js`.

Relevant files:
- `packages/service-agent/src/AgentService.ts`
- `packages/service-agent/package.json`
- `node_modules/.bun/@earendil-works+pi-coding-agent@0.80.10/.../dist/index.js`
- `node_modules/.bun/@earendil-works+pi-coding-agent@0.80.10/.../dist/core/model-runtime.js`
- `node_modules/.bun/@earendil-works+pi-coding-agent@0.80.10/.../dist/core/auth-storage.js`
- `node_modules/.bun/@earendil-works+pi-coding-agent@0.80.10/.../CHANGELOG.md`

## Plan

1. Remove `AuthStorage` from `AgentService.ts` import
2. Remove `authStorage` field, keep only `modelRuntime: ModelRuntime`
3. Move `ModelRuntime.create({ authPath, modelsPath })` into the async `start()` method
4. Replace `authStorage.login(...)` → `modelRuntime.login(providerId, 'oauth', interaction)`
5. Replace `authStorage.logout(...)` → `modelRuntime.logout(providerId)`
6. Replace `authStorage.set(...)` → `modelRuntime.login(providerId, 'api_key', { prompt: async () => key, ... })` or `modelRuntime.setRuntimeApiKey(...)`
7. Replace `authStorage.remove(...)` → `modelRuntime.logout(providerId)`
8. Replace `authStorage.list()` → `modelRuntime.listCredentials()`
9. Replace `modelRegistry.getAll()` → `modelRuntime.getModels()`
10. Replace `modelRegistry.getAvailable()` → `modelRuntime.getAvailableSnapshot()`
11. Replace `modelRegistry.find(...)` → `modelRuntime.getModel(...)`
12. Replace `createAgentSessionServices({ authStorage, modelRegistry })` → `createAgentSessionServices({ modelRuntime })`
13. Update `IPublicMethods` interface return types from `void` to `Promise<void>`
14. Run typecheck

## NOTES

- `ModelRuntime.create()` is async, so initialization moves from constructor to `start()`
- The `modelRuntime.login()` for OAuth takes `(providerId, 'oauth', AuthInteraction)` — the interaction maps old `onDeviceCode`/`onProgress` callbacks to `notify()` events and `onPrompt`/`onSelect` to `prompt()` calls
- For API key persistence via `modelRuntime.login(providerId, 'api_key', interaction)`, the `prompt` callback returns the key directly; this triggers the provider's `apiKey.login()` which persists the credential
- `modelRuntime.setRuntimeApiKey()` is in-memory only (not persisted to auth.json) — prefer `login()` for persistence
- `modelRuntime.listCredentials()` returns `Promise<readonly CredentialInfo[]>` matching the old synchronous `authStorage.list()` contract
