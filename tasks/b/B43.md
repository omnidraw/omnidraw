# B43 - widgets: optimize Arrow sandbox dependency chain under TypeScript 7
[Overview](../BASED.md)

Keep workspace TypeScript 7 while allowing Arrow Sandbox to use and bundle its TypeScript 5 compiler and QuickJS runtime correctly.

## Context

The frontend excluded Arrow Sandbox and QuickJS from Vite dependency optimization while explicitly optimizing root TypeScript 7. Arrow Sandbox 1.0.6 imports its own TypeScript 5 dependency as a default CommonJS export, which failed when served directly. Optimizing only the sandbox while excluding QuickJS produced an unresolved bare QuickJS import.

## Plan

Optimize the complete `@vibecanvas/canvas > @arrow-js/sandbox` dependency chain and allow its QuickJS dependencies to be bundled normally.
