# B87 - ci: install Playwright Chromium before host browser acceptance
[Overview](../BASED.md)

Final acceptance reaches the packed canvas-kernel browser smoke but cannot
launch Chromium because the GitHub Actions job installs Playwright's package
without downloading its matching browser binary.

## Context

[GitHub Actions run 31384873447](https://github.com/omnidraw/vibecanvas/actions/runs/31384873447)
passed the durable architecture, public-package, and load suites before
`scripts/test-packed-canvas-kernel.ts` launched the isolated consumer. Its
Playwright `1.61.1` process then failed because the expected
`chromium_headless_shell-1228` executable was absent from the runner cache.

The repository's host final acceptance deliberately owns browser and nested
OCI gates. Installing npm dependencies alone does not provision Playwright's
version-matched browser or Linux system dependencies.

## Plan

1. Install Playwright's pinned Chromium and required Linux dependencies after
   the frozen dependency install and before final acceptance.
2. Add an architecture regression assertion that preserves this ordering.
3. Run the focused architecture suite, validate the Playwright command, then
   commit, push, and monitor GitHub Actions.

No mockup or diagram is useful for this CI bootstrap correction.
