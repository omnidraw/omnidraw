# D4 - canvas: audit and remove unused `@chenglou/pretext` code paths
[Overview](../../`BASED`.md)

<Find and remove all unused code paths related to @chenglou/pretext in packages/canvas/>

## Context
`@chenglou/pretext` (a text layout library) is a dependency of `@vibecanvas/canvas`.
`src/core/fx.pretext.ts` exports `fxMeasureTextLayout()` which uses `pretext`'s
`layoutWithLines` and `prepareWithSegments` via a portal. However, this function is
not imported or consumed by any file in the workspace, making it dead code.

`src/core/fn.pretext.ts` (`fnBuildPretextFont`) is also only imported by `fx.pretext.ts`
and has no other consumers.

The `pretext` dependency itself is only referenced in `package.json` and these two files.

## Plan
- [ ] Verify `fxMeasureTextLayout` has no external consumers (apps, other packages)
- [ ] Remove `src/core/fx.pretext.ts` and `src/core/fn.pretext.ts`
- [ ] Remove `@chenglou/pretext` from `packages/canvas/package.json` dependencies
- [ ] Remove `pretext` from any tsconfig path mappings if present
- [ ] Run `bun run test` in `packages/canvas` to confirm no breakage
- [ ] Run `bunx tsc -p packages/canvas/tsconfig.json --noEmit` to confirm type safety
- [ ] Run `bun run lint:functional-core:agent` to confirm lint compliance
