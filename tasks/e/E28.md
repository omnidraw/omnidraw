# E28 - codex workspace copy: local-volume and actor manifest path rewrite
[Overview](../BASED.md)

Explore/fix Codex workspace switching/copying so copied widgets keep working without manifest path conflicts.

## Context
When changing or copying a Codex workspace, we also need to copy the `local-volume` folder. The database currently keeps `actor_definitions.manifest_path` values pointing at the old workspace path. Because widgets are copied but paths still reference the old workspace, the new workspace can hit path mismatch problems and unique constraint errors.

Expected behavior:
- Copy `local-volume` into the new workspace copy.
- Rewrite DB `actor_definitions.manifest_path` so the workspace directory prefix is replaced with the new workspace directory.
- Preserve the rest of each manifest path after the workspace root so the copied widget/actor layout still matches.
- Avoid `actor_definitions` unique constraint collisions after copy.

Relevant areas to investigate:
- Codex workspace copy/change flow.
- DB tables and migrations around `actor_definitions`.
- Any widget copy/import path normalization code.
- `local-volume` runtime/workspace storage assumptions.

## Plan
Find the workspace copy/change implementation, identify where DB rows and local files are cloned, then design a path-rewrite step for actor manifests and include `local-volume` in copied workspace assets.
