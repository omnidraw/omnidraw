# S71 - image paste: render local preview while uploading to remote server
[Overview](../../BASED.md)

Image paste should feel instant when the server is remote by rendering a local preview before upload/transmission finishes.

## Context
Pasting images is slow when the backing server is remote because the canvas waits for the image to transmit/persist before rendering it. The UX should optimistically show the pasted image locally immediately, then reconcile it with the persisted image record once upload completes.

Relevant areas to inspect:
- canvas image paste handling
- image element creation and persistence
- image blob storage/upload path
- remote/server latency behavior

## Plan
1. Find the current paste-to-image flow from clipboard read to canvas element render.
2. Identify where the UI blocks on upload/persistence.
3. Add an optimistic local image source path using a local blob/object URL or equivalent temporary source.
4. Swap temporary source to persisted image source after upload succeeds.
5. Handle upload failure by showing clear error state or removing the optimistic image.
6. Verify local and remote server paste behavior.
