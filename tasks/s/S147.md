## Plan

### 1. Cut every authoring and runtime surface over

- Update widget scaffolds, examples, agent prompts, check/build diagnostics,
  build receipts, accepted-generation metadata, Preview, publication,
  `release.json`, catalog scanning, inspection, and CLI output to the fixed
  portable contract.
- Delete old manifest fields, server envelope files, and development
  publications. The format is unreleased, so do not add an automatic rewrite,
  migration command, legacy reader, dual publication, fallback runner, or
  user-facing migration instructions.

### 2. Delete superseded code and vocabulary

- Delete the JSON/base64 envelope, output-list types, arbitrary runtime ABI
  plumbing, source module paths in public descriptors, Bun-target fixtures,
  and adapter switches.
- Remove or rename local “sandbox” documentation and code identifiers that
  overstate the OSS trust boundary while preserving actual child cleanup and
  defense-in-depth checks.
- Remove stale managed Microsandbox function diagrams and references from
  current authorities; keep completed task history unchanged.
- Add negative inventories so Cloudflare/Turso managed implementation code
  cannot drift into OSS later.

### 3. Release the public change

- Select the next unused SDK release marker required by repository publishing
  rules, update the package version, regenerate `bun.lock`, and update
  `public-package-set.json`. This is qualification of the first released
  format, not a downstream format migration.
- Rebuild staged declarations and manifests; confirm internal dependencies are
  exact and catalog dependencies resolve to registry ranges.
- Update packed and fake managed consumers to the exact qualified package set.
  Do not publish from the workspace root or overwrite an existing version.

### 4. Run the final qualification matrix

- Run SDK contract/server/resource/conformance tests, backend widget build/
  publication/catalog/Preview/inspection/function/resource/API tests,
  architecture tests, and all affected typechecks.
- Run the complete staged package build/pack/import verification, packed
  external composition, source-run widget CLI repair loop, and browser Preview
  function/resource acceptance.
- Prove no resident function child remains after completion, timeout,
  cancellation, disconnect, or failure; no invocation history survives
  restart; and OSS uses no network/cloud executor for a function.
- Record the exact external managed follow-up: adopt the released SDK, generate
  the WFP wrapper from exact server bytes, run real dispatch/Turso conformance,
  prove Worker-only execution with no filesystem/OS authority, and reject the
  package set until that private gate passes.
