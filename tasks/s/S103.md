# S103 - remove PTY service, API, canvas terminal, and SQL metadata
[Overview](../../BASED.md)

Remove the full PTY stack: server service, API domain, canvas terminal plugin, client helpers, package, SQL table, and tests. Edit the existing SQL file directly (no new migration — nothing deployed yet).

## Context

`service-pty` is not deprecated in the backend. The canvas terminal surface is disabled, but the network-capable PTY service remains fully live.

| Area | Current state |
|---|---|
| SQL metadata | `pty_session_metadata` is unused schema: it appears only in DDL/schema expectations and docs, with no runtime query or write. |
| PTY runtime | Active: `PtyServiceBunPty.ts` keeps real `bun-pty` processes in an in-memory `#sessions` map, including a 4 MiB replay buffer. It is lost on server restart. |
| API | Active: `packages/api/src/pty` publishes list/create/get/update/remove and clipboard-image upload through the `/api` oRPC WebSocket. |
| Network stream | Active: `PtyPlugin.ts` exposes raw terminal I/O at `GET /api/pty/:ptyID/connect` over WebSocket. |
| CLI composition | Active in every `serve` run: `setup-services.ts` constructs and registers it; `main-app.ts` installs the WebSocket plugin. |
| Canvas | Dormant, not removed: `runtime.ts` comments out `createTerminalPlugin()`. The terminal implementation, exports, CSS, `ghostty-web` dependency, and toolbar type still exist. |

## Plan

### Step 1: Remove the live server surface

- Delete `apps/cli/src/plugins/pty/PtyPlugin.ts` and its registration in `main-app.ts:92`.
- Remove PTY service construction/registration and service type from `apps/cli/src/setup-services.ts:155`.
- Remove PTY dependency injection from the oRPC plugin.
- Delete the entire `packages/api/src/pty` domain, root router/context/handler registrations, exports, and `@vibecanvas/service-pty` dependency.

### Step 2: Remove client/UI remnants

- Delete `packages/canvas/src/plugins/terminal/`.
- Remove terminal plugin export, toolbar `"terminal"` type remnants, and `ghostty-web`.
- Remove PTY clipboard-upload helper/type from `packages/orpc-client/src/index.ts:31`.

### Step 3: Remove the package and infrastructure

- Delete `packages/service-pty`.
- Remove CLI/API package dependencies, root test filter, lockfile entry.
- Remove PTY isolation/setup/plugin/API tests and the PTY section of `scripts/test-isolation.ts`.

### Step 4: Remove unused home-layout state

- Remove `ptyRoot` from Vibecanvas-home resolution and initialization.
- Remove the expected `pty` leaf in DB preflight and associated tests.
- Edit the existing SQL file directly to remove the `pty_session_metadata` table and indexes (no new migration — nothing has been deployed yet).

### Step 5: Canvas terminal compatibility check

Existing canvases may contain persisted `ui-widget` terminal payloads. The runtime currently makes them inert; removal should either migrate them to a safe placeholder or explicitly preserve unknown widgets.
