# S116 - canvas: delete the retired collaboration and parallel canvas architecture
[Overview](../BASED.md)

Immediately after A92, delete the unused collaboration implementation, legacy
canvas vocabulary, projection machinery, compatibility fixtures, and patch
tooling.

## Result

The retired service package, server route/plugin, browser repository/cache,
document types, CRDT builders, projection engine, legacy product services,
fixtures, dependencies, lock entries, and throttle patch hook are deleted.

The remaining architecture is:

- `canvas_items` JSONB as authored Cangine state;
- CanvasService as the sole canvas authority;
- WidgetStateService as the sole widget-state authority;
- local bounded current-user history;
- runtime-only layers and portals.

A repository architecture gate now rejects removed dependencies, routes,
document handles/types, schema tables/columns, projectors, adapters, and
compatibility paths.
