# S141 - widgets: remove author-selected runtimes from the server contract (order 2/8)
[Overview](../BASED.md)

Make the SDK the sole owner of a fixed server ABI and remove host runtime names
and source paths from portable widget metadata.

## Context

The strict manifest currently accepts
`server: { entry, runtimeAbi }`, release descriptors repeat that author-chosen
value, and tests use incompatible values such as `bun-v1`,
`quickjs-release-sync-v1`, and `omnidraw-function-v1`. A widget author should
choose server source, functions, schemas, effects, resources, and limits—not
the product's execution engine.

Relevant owners:

- [SDK contract types](../../packages/sdk/src/contracts/types.ts)
- [SDK validators](../../packages/sdk/src/contracts/schema.ts)

## Plan

### 1. Fix the manifest and ABI

- Change manifest-v1 server configuration to contain only the authored source
  `entry`. The SDK exports one exact Omnidraw server ABI constant.
- Keep an exact ABI/format marker in the canonical artifact and attested
  release so hosts can reject incompatible bytes, but derive it exclusively
  from the SDK versioned contract.
- Make check, executable projection, input digests, release validation, and
  build receipts reject an authored `runtimeAbi` field.
- The format is unreleased. Change manifest v1 and the artifact format in place,
  delete superseded development fixtures/publications, and add no migration,
  legacy decoder, compatibility branch, or user-facing conversion workflow.

### 2. Define the canonical server artifact

- Replace the generic `TWidgetServerBuildArtifact.bytes` contract with an
  explicit, immutable ES-module artifact containing the fixed format/ABI,
  exact module bytes, SHA-256 digest, and bounded canonical function
  descriptors.
- Bind the manifest projection, server module digest, descriptor digest,
  SDK/toolchain identity, and UI artifact into the widget construction and
  final artifact digests.
- Keep the server module independent of a Cloudflare Fetch wrapper, request
  routing, environment bindings, and OSS IPC.
- Remove `modulePath` from published function descriptors. Source-module
  association may exist transiently inside the builder, but neither
  `functions.json`, the browser projection, nor host invocation needs a
  filesystem path after bundling.

### 3. Freeze the serializable function contract

- Keep named exports, `fn | fx | tx`, input/output JSON Schema, declared
  resource effects, timeout, memory tier, output limit, and log limit as the
  complete author-visible registration.
- Define exact validation, canonical ordering, duplicate-export rejection,
  bounded value rules, and stable failure codes in SDK-owned pure code.
- Ensure every public declaration remains Effect-free, Capsule-neutral,
  transport-neutral, and free of Bun, Node, Cloudflare, Turso, auth, and
  billing types.
