# S97 - compress task reference images
[Overview](../BASED.md)

Reduce the repository payload of every raster reference image under `tasks/` while preserving readable UI details and valid Markdown references.

## Context

The task archive contains three PNG screenshots totaling 2,940,160 bytes. They are documentation/reference images rather than pixel-exact source assets, so high-quality WebP is appropriate.

## Plan

1. Inventory all task images and their references.
2. Benchmark lossless PNG, lossless WebP, and high-quality WebP encodings.
3. Apply the smallest visually acceptable encoding and update references.
4. Verify rendering, dimensions, links, and final size.
