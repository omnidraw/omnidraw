# S101 - Relax home directory validation
[Overview](../../BASED.md)

Allow unknown entries in `.vibecanvas` home directory without throwing.

## Context

`validateVibecanvasHomeLayout` (packages/service-db/src/DbServiceTurso/DbServiceTurso.ts:199-293) throws on any unknown entry (.DS_Store, autoupdate-state.json, etc.). This is overly strict — macOS auto-creates .DS_Store in any directory you open in Finder, so the home dir becomes "contaminated" immediately.

## Plan

### Step 1: Relax catch-all validation

In `packages/service-db/src/DbServiceTurso/DbServiceTurso.ts`, change the final catch-all at line 289 from `throw` to `continue` (skip unknown entries silently). Only throw when there's a genuine structural conflict (file where directory expected, wrong checksum, etc.).

### Step 2: Update test

Update `packages/service-db/src/tests/BunServiceTurso/tx.migrations.test.ts` lines 1108-1119 — the `vibecanvas.turso` test should now succeed (or at least not throw on unknown entry) since the home dir has a non-conflicting legacy file with no database to conflict with. Depending on how we want to handle actor-era files, we may keep the throw for files that look like a known legacy format (.sqlite, .turso) but the .DS_Store / random JSON case should be tolerated.
