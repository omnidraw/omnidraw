# S95 - sidebar: unify selected widget highlight
[Overview](../BASED.md)

Give the active widget row the same clear selected treatment used for canvases and resources.

## Context

Widget rows are rendered by [`packages/ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.tsx`](../../packages/ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.tsx) and styled in [`packages/ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.module.css`](../../packages/ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.module.css). Selection matching and styles already exist, but the active widget is not visibly highlighted in the supplied widget-detail view.

Canvas and resource selection provide the expected reference behavior in [`packages/ai-chat/src/sidebar/components/Sidebar.tsx`](../../packages/ai-chat/src/sidebar/components/Sidebar.tsx) and [`packages/ai-chat/src/sidebar/components/SidebarItem.module.css`](../../packages/ai-chat/src/sidebar/components/SidebarItem.module.css).

The highlight must identify the exact selected variant when a widget has both published and draft rows with the same display name.

## Plan

1. Diagnose why widget route selection is not producing a visible active row.
2. Make widget selection react correctly to detail-route navigation and distinguish draft from published sources.
3. Align the selected visual state with canvas and resource rows across themes, hover, and keyboard focus.
4. Preserve `aria-current` on only the active row.
5. Add focused selection and rendering tests.
