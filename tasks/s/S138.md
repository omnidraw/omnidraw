# S138 - widgets: remove obsolete revision, Preview, artifact, group, Runs, and Logs surfaces

[Overview](../BASED.md)

Delete the public and internal product surfaces that describe the old database
widget system after replacement flows are working.

## Context

[S136](./S136.md) removes widget control-plane authority, [S137](./S137.md)
removes durable function history, and [A110](../a/A110.md) supplies the
replacement Config and catalog UI. This task removes the remaining vocabulary,
routes, contracts, and tests so old concepts cannot return through dead code.

## Plan

### 1. Remove obsolete API and UI

- Remove revision lists, pinning, rollback, artifact views, group CRUD,
  persisted Preview status, Runs, Logs, attempts, usage, and cancel/status
  controls.
- Remove matching oRPC contracts, clients, handlers, events, hooks, stores,
  components, commands, and SDK promises.

### 2. Remove compatibility residue

- Delete dual-read flags, old response shapes, aliases, adapters, fixtures, and
  fallback UI.
- Remove old task-era terminology from help, errors, tests, and public docs.
- Keep only the current filesystem health, Config, Preview, Publish, and direct
  function actions.

### 3. Prove the subtraction

- Add repository checks for forbidden table names, APIs, and product wording.
- Run transport, UI, SDK, and package-boundary tests after deletion.
