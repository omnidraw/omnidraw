# S82 - keep AI wizard Tool tab synchronized with sidebar tool changes
[Overview](../BASED.md)

Make sidebar tool-group mutations immediately available in the AI wizard Tool tab without a page refresh.

## Context

The frontend sidebar loads and mutates tool groups in [`apps/frontend/src/feature/sidebar/components/Sidebar.tsx`](../../apps/frontend/src/feature/sidebar/components/Sidebar.tsx). The AI wizard receives a separate `existingGroups` snapshot and renders it in [`packages/canvas/src/components/AiWizzard/tabs/ToolTab.tsx`](../../packages/canvas/src/components/AiWizzard/tabs/ToolTab.tsx). Creating, renaming, or deleting a group in the sidebar can therefore leave an already-mounted Tool tab stale until refresh.

The implementation should establish one live update path for tool metadata and ensure the Tool tab handles deletion or rename of its currently selected group predictably.

## Plan

Trace ownership of the sidebar group list and AI wizard `toolGroupState`, then connect mutations to a shared reactive refresh/invalidation path instead of maintaining isolated snapshots.
