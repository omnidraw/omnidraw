# S96 - AI mentions: live resource and widget catalog
[Overview](../BASED.md)

Replace the stale resource-only mention menu with one live, compact catalog of resources and widgets across every AI chat.

## Context

Each AI chat currently loads resource mentions into local state in [`packages/ai-chat/src/chat/components/index.tsx`](../../packages/ai-chat/src/chat/components/index.tsx). Resource creation performed through that same chat can trigger a refetch, but resources added, renamed, or removed elsewhere do not update all mounted chat menus until the browser reloads.

Mention item data and rendering are owned by [`packages/ai-chat/src/chat/components/ChatComposer/interface.ts`](../../packages/ai-chat/src/chat/components/ChatComposer/interface.ts), [`packages/ai-chat/src/chat/components/ChatComposer/ChatComposer.tsx`](../../packages/ai-chat/src/chat/components/ChatComposer/ChatComposer.tsx), and [`packages/ai-chat/src/chat/components/index.css`](../../packages/ai-chat/src/chat/components/index.css). The existing widget catalog already refreshes from events in [`packages/ai-chat/src/sidebar/widgets/WidgetCatalogProvider.tsx`](../../packages/ai-chat/src/sidebar/widgets/WidgetCatalogProvider.tsx).

The unified mention menu should include resources and widgets. Each item must fit on one line, show a resource-type icon for resources or the configured widget icon for widgets, and remain identifiable when names collide.

## Plan

1. Introduce a shared reactive mention catalog instead of independently loaded resource lists in each chat instance.
2. Refresh or reconcile that catalog when resources or widgets are created, removed, renamed, updated, drafted, or published, regardless of which UI initiated the change.
3. Extend mention identity and prompt handling to distinguish resource and widget targets safely.
4. Add widget mention entries using their configured icons and define how draft/published variants are represented when both exist.
5. Redesign mention suggestions as compact single-line rows with icon, name, and concise type/source metadata.
6. Add focused tests for live cross-menu updates, target identity, filtering, keyboard navigation, icon rendering, and one-line layout semantics.
