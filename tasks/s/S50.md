# S50 - remove legacy hosted file, filetree, terminal element code
[Overview](../../BASED.md)

Remove old Solid hosted component directories and deprecated canvas-doc element variants now replaced by trusted widgets.

## Context

Removed legacy UI directories:
- `packages/canvas/src/components/file/`
- `packages/canvas/src/components/filetree/`
- `packages/canvas/src/components/terminal/`

Removed deprecated schema variants:
- `zFileData`
- `zFiletreeData`
- `zTerminalData`
- `zIframeBrowserData`

The current replacement path is trusted widget data via `data.type === 'widget'` and plugin-specific `kind`/`payload`.

## Plan

1. Delete old Solid component directories.
2. Move the still-used CodeMirror language helper into the filesystem plugin.
3. Remove deprecated file/filetree/terminal data schemas and exported types.
4. Update canvas command bounds helpers to use generic `w/h` detection for current widgets.
5. Update stale CLI fixture data.
6. Update bookkeeping.
