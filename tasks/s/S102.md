# S102 - Dev server uses local .vibecanvas
[Overview](../../BASED.md)

Isolate dev server data from production by using repo-local `.vibecanvas`.

## Context

`bun run dev` resolves home to `~/.vibecanvas`, which is shared with any production CLI install. Dev data and prod data collide.

## Plan

### Step 1: Set VIBECANVAS_HOME in dev script

In `scripts/dev.ts`, add `VIBECANVAS_HOME: path.join(rootDir, '.vibecanvas')` to the cli process env (line 288-293) in the `spawnDevProcess` call.

### Step 2: Update .gitignore

Add `.vibecanvas/` entry to `.gitignore` so the local dev home doesn't get committed.

## NOTES

After this change:
- `bun run dev` will use `<repo>/.vibecanvas` automatically
- `bun run --watch ./src/main.ts serve` (standalone CLI) still defaults to `~/.vibecanvas`

Dev isolation is achieved without requiring `--data-dir` each time.
