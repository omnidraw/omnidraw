# S74 - update workspace dependencies in safe coordinated batches
[Overview](../BASED.md)

Reduce dependency drift across all workspace packages while keeping major migrations isolated from routine updates.

## Context

The repository contains 29 workspace `package.json` files governed by the root [package.json](../../package.json) catalog and overrides. `bun outdated --recursive` identified routine patch/minor updates, coordinated dependency families, and several major-version migrations.

Important constraints:
- Keep Automerge packages version-aligned.
- Preserve [scripts/patch-automerge-repo-throttle.mjs](../../scripts/patch-automerge-repo-throttle.mjs) unless the upstream fix is verified and the postinstall hook is intentionally removed.
- Keep `@orpc/client`, `@orpc/contract`, and `@orpc/server` aligned.
- Update root CodeMirror overrides together with canvas declarations.
- Major upgrades for Konva, PDF.js, Astro, Vite, jsdom, and TypeScript require separate compatibility work.

## Plan

### 1. Capture baseline

- Run the full test suite and build before dependency changes.
- Save the current recursive outdated report for comparison.
- Identify existing failures so they are not attributed to updates.

### 2. Update routine tooling and libraries

- Update root tooling patches/minors: `bun-types`, ESLint, and TypeScript ESLint parser.
- Update Vitest and remain on Vite 7.
- Update routine UI/runtime dependencies including Solid, Kobalte, Lucide, PartySocket, DOMPurify, ProseMirror, TypeBox, Bun PTY, and Astro 5.
- Avoid major versions in this lane.

### 3. Update coordinated dependency families

- Update all oRPC packages to the same version.
- Update Automerge core, repo, network, and storage packages together.
- Verify whether Automerge Repo 2.5.6 still needs the negative-timeout patch; do not remove it without proof.
- Update Turso database packages together.
- Update CodeMirror packages and root overrides as one change.
- Update Zod and run API/schema coverage across consumers.

### 4. Validate

- Regenerate the Bun lockfile using the repository package manager.
- Run functional-core lint, tests, build, binary tests, and relevant workspace checks.
- Smoke-test CRDT synchronization, websocket reconnection, editor behavior, PTY lifecycle, icons, and database startup.
- Run `bun outdated --recursive` again and document intentionally deferred versions.

### 5. Keep major migrations separate

- Defer Konva 10, PDF.js 6, Astro 7 integrations, Vite 8, jsdom 29, and TypeScript 7.
- Assess `@chenglou/pretext` independently because it is pre-1.0.
- Create dedicated follow-up tasks for major upgrades that are still desired after routine updates land.
