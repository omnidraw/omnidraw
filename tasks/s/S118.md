# S118 - canvas: remove generic widget catalog toolbar plumbing
[Overview](../BASED.md)

Remove generic widget-catalog entry points and catalog plumbing from the canvas
toolbar. Draft and published widgets remain available through the sidebar,
which is their authoritative placement UI. The dedicated AI Chat creation tool
is separate and must remain in the toolbar.

## Context

The canvas runtime still accepted a toolbar-group catalog that no longer
rendered anything. That duplicated the sidebar and kept an unused
frontend-to-canvas data path.

S118 incorrectly treated the dedicated AI Chat creation entry as part of that
generic widget catalog. Removing the catalog entry and plumbing was valid;
removing the AI Chat tool and its `C` shortcut was a regression because empty
canvases then had no way to create an AI Chat frame.

## Plan

- Keep the dedicated AI Chat toolbar button and its `C` shortcut.
- Delete the unused toolbar-group canvas port and frontend adapter.
- Delete the now-unobserved toolbar-group invalidation channel.
- Update active UI copy and screen documentation to point to the sidebar.
- Preserve widget placement through the sidebar.
