# S118 - canvas: toolbar should not include widget icons
[Overview](../BASED.md)

Remove widget entry points and catalog plumbing from the canvas toolbar. Widgets
remain available through the sidebar, which is the authoritative placement UI.

## Context

The floating canvas toolbar still exposes an AI/widget tool and the canvas
runtime still accepts a toolbar-group catalog that no longer renders anything.
This duplicates the sidebar and keeps an unused frontend-to-canvas data path.

Relevant surfaces:

- [`FloatingCanvasToolbar/index.tsx`](../../packages/canvas/src/components/FloatingCanvasToolbar/index.tsx)
- [`Canvas.tsx`](../../packages/canvas/src/components/Canvas.tsx)
- [`types.ts`](../../packages/canvas/src/types.ts)
- [`canvas.tsx`](../../apps/frontend/src/pages/canvas.tsx)
- [`ai-chat-adapters.ts`](../../apps/frontend/src/ai-chat-adapters.ts)
- [`ports.ts`](../../packages/ui-ai-chat/src/sidebar/ports.ts)

## Plan

- Delete the AI/widget toolbar button and its keyboard shortcut.
- Delete the unused toolbar-group canvas port and frontend adapter.
- Delete the now-unobserved toolbar-group invalidation channel.
- Update active UI copy and screen documentation to point to the sidebar.
- Preserve widget placement through the sidebar.
