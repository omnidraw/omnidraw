# S100 - sidebar: toggle tool groups from the whole row
[Overview](../BASED.md)

Make each widget tool-group row act as one clear disclosure target, while keeping its three-dot actions menu independent.

## Context

In [`packages/ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.tsx`](../../packages/ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.tsx), only the small chevron button currently calls `toggleGroup`. The parent **Widgets** section already provides the expected behavior: its title area is the disclosure control. Tool groups should match that interaction so clicking the chevron, icon, group name, or unused row space expands/collapses the group.

The trailing three-dot menu is the exception. Clicking it or selecting one of its actions must only operate the menu and must never toggle the group underneath. Styles live in [`packages/ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.module.css`](../../packages/ai-chat/src/sidebar/widgets/components/WidgetsSidebarSection.module.css).

## Plan

![Tool-group row reference; the row toggles except for the three-dot menu](S100.webp)

1. Restructure the group row into a full-width disclosure control plus a separate trailing actions-menu control, avoiding nested interactive elements.
2. Make the disclosure hit area include the chevron, group icon, name, and blank row space while excluding the three-dot button.
3. Keep `aria-expanded`, an accurate accessible label, and keyboard activation on the full disclosure target; rotate/update the chevron from the same expanded state.
4. Ensure pointer and keyboard events from the three-dot trigger, menu portal, and menu items cannot bubble into the disclosure toggle.
5. Preserve selected-widget auto-expansion, empty-group rendering, hover/selected styling, and group edit behavior.
6. Add focused Solid tests proving row/icon/name clicks and Enter/Space toggle exactly once, while three-dot/menu interactions do not toggle.

## Acceptance criteria

- Clicking anywhere on a tool-group row except the three-dot menu toggles that group.
- Clicking the three-dot trigger or a menu action never expands or collapses the group.
- Enter and Space toggle the focused group disclosure exactly once.
- `aria-expanded` always matches the visible children and the chevron state.
- Opening a selected widget still reveals its containing group automatically.
