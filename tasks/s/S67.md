# S67 - floating menu only when element is selected
[Overview](../../BASED.md)

Keep drawing area free by hiding the floating menu during tool-only selection.

## Context
The floating menu currently appears when a drawing tool is selected, even if no canvas element is selected. This blocks drawing space and should only appear for an actual selected element.

Relevant area to inspect when implementing:
- canvas selection state
- floating/style menu visibility logic
- drawing tool selection UI

## Plan
1. Find the floating/style menu visibility condition.
2. Separate tool selection state from element selection state.
3. Show the floating menu only when at least one element is selected.
4. Verify drawing tools no longer open the menu by themselves.
